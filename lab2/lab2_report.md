* Перевірити коректність обчислень на контрольних прикладах і побудувати графік залежності похибки від n.

## Умова завдання (варіант 15)

Задано натуральне число n та значення $x = \frac{1}{3}$. Обчислити суму ряду:

$$S = \sum_{i=0}^{n} (-1)^i x^i$$

Точне значення суми нескінченного ряду ($n \to \infty$) для $|x| < 1$ становить:

$$S_{\text{точн}} = \frac{1}{1 + x} = \frac{1}{1 + \frac{1}{3}} = \frac{3}{4} = 0.75$$

## 3. Текст обох програм

### Програма 1
```c
#include <stdio.h>

int main(void) {
    int n;
    printf("Enter n (n>0): ");
    if (scanf("%d", &n) != 1 || n <= 0) {
        return 1;
    }

    const double x = 1.0 / 3.0;
    double sum = 0.0;

    for (int i = 0; i <= n; ++i) {
        double power_x = 1.0;
        for (int j = 0; j < i; ++j) {
            power_x *= x;
        }

        double sign = (i % 2 == 0) ? 1.0 : -1.0;
        sum += sign * power_x;
    }

    printf("%.7lf\n", sum);
    return 0;
}
```

### Програма 2
```c
#include <stdio.h>
int main(void) {
    int n;
    printf("Enter n (n>0): ");
    if (scanf("%d", &n) != 1 || n <= 0) {
        return 1;
    }

    const double x = 1.0 / 3.0;
    const double factor = -x;
    double term = 1.0;
    double sum = 0.0;

    for (int i = 0; i <= n; ++i) {
        sum += term;
        term *= factor;
    }

    printf("%.7lf\n", sum);
    return 0;
}
```

## 4. Розрахунок кількості операцій для кожного з алгоритмів

Відповідно до методики оцінювання ітераційних алгоритмів, часова складність у навчальній моделі подається формулою:

$$T = K_C t_1 + K_A t_2 + K_L t_3 + K_{as} t_4$$

де:
* $K_C$ — кількість операцій порівняння;
* $K_A$ — кількість арифметичних операцій;
* $K_L$ — кількість повторень циклів;
* $K_{as}$ — кількість операцій присвоювання;
* $t_1, t_2, t_3, t_4$ — тривалості виконання відповідних операцій (у спрощеній моделі приймаються за константи).

Окремо враховуються виклики стандартних бібліотечних функцій (`scanf`, `printf`). Обидві програми працюють для натурального $n \ge 1$ із типом `double` та без використання `pow()`.

### 1. Алгоритм 1 (`task1.c` — вкладені цикли)

Зовнішній цикл по `i` виконується від `0` до `n` включно ($n + 1$ ітерацій), а внутрішній цикл по `j` для кожного фіксованого `i` виконується `i` разів, що сумарно дає $\sum_{i=0}^{n} i = \frac{n(n+1)}{2}$ повторень.

* **Кількість повторень циклів ($K_L$):**
  $$K_L = (n + 1) + \frac{n(n+1)}{2} = \frac{(n+1)(n+2)}{2}$$
* **Кількість арифметичних операцій ($K_A$):**
  $$K_A = 1 + 3(n + 1) + \frac{n(n+1)}{2}$$
  *(1 ділення `1.0 / 3.0`, по 3 операції на кожній з $n+1$ ітерацій зовнішнього циклу: `%`, `*`, `+`, а також $\frac{n(n+1)}{2}$ множень `power_x *= x` у внутрішньому циклі)*
* **Кількість операцій порівняння ($K_C$):**
  $$K_C = 2 + (n + 2) + (n + 1) + \frac{(n+1)(n+2)}{2} = 2n + 5 + \frac{(n+1)(n+2)}{2}$$
  *(2 перевірки вводу, $n+2$ перевірок умови `i <= n`, $n+1$ перевірок парності `i % 2 == 0` та $\frac{(n+1)(n+2)}{2}$ перевірок умови `j < i`)*
* **Кількість операцій присвоювання ($K_{as}$):**
  $$K_{as} = 2 + 5(n + 1) + n(n + 1) = n^2 + 6n + 7$$
* **Виклики стандартних функцій:** **2** виклики (`scanf` — 1 раз, `printf` — 1 раз; функції з `math.h` не викликаються).
* **Порядок складності:** через наявність квадратичного доданку $\frac{n(n+1)}{2}$ алгоритм має квадратичну часову складність — **$O(n^2)$**.

### 2. Алгоритм 2 (`task2.c` — один цикл, динамічне програмування)

У другому алгоритмі кожен наступний член ряду обчислюється через попередній множенням на сталий множник `factor = -x`, тому вкладений цикл відсутній і все тіло циклу виконується $n + 1$ разів.

* **Кількість повторень циклів ($K_L$):**
  $$K_L = n + 1$$
* **Кількість арифметичних операцій ($K_A$):**
  $$K_A = 2 + 2(n + 1) = 2n + 4$$
  *(ділення `1.0 / 3.0` та унарний мінус `-x` до циклу; додавання `sum += term` і множення `term *= factor` на кожній із $n+1$ ітерацій)*
* **Кількість операцій порівняння ($K_C$):**
  $$K_C = 2 + (n + 2) = n + 4$$
  *(2 перевірки вводу та $n+2$ перевірок умови циклу `i <= n`)*
* **Кількість операцій присвоювання ($K_{as}$):**
  $$K_{as} = 4 + 3(n + 1) = 3n + 7$$
* **Виклики стандартних функцій:** **2** виклики (`scanf` — 1 раз, `printf` — 1 раз).
* **Порядок складності:** усі складові зростають лінійно зі збільшенням `n`, тому часова складність алгоритму — **$O(n)$**.
