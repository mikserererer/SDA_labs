## 2. Завдання на лабораторну роботу і умови завдання

* Створити дві програми: першу — із використанням вкладених циклів, другу — в один цикл із застосуванням методу динамічного програмування.
* Забезпечити введення натурального числа n (n >= 1) та перевірку коректності вхідних даних.
* Використовувати тип double для проміжних і підсумкових обчислень та виводити результат з 7 цифрами після коми.
* Підрахувати кількість операцій для обох алгоритмів (окремо врахувавши виклики стандартних функцій) та визначити порядок складності.
* Перевірити коректність обчислень на контрольних прикладах і побудувати графік залежності похибки від n.

## Умова завдання (варіант 15)

Задано натуральне число n та значення $x = \frac{1}{3}$. Обчислити суму ряду:

$$S = \sum_{i=0}^{n} (-1)^i x^i$$

Точне значення суми нескінченного ряду ($n \to \infty$) для $|x| < 1$ становить:

$$S_{\text{точн}} = \frac{1}{1 + x} = \frac{1}{1 + \frac{1}{3}} = \frac{3}{4} = 0.75$$

## 3. Текст обох програм

### Програма 1
```c
#include <stdio.h>

int main(void) {
    int n;
    printf("Enter n (n>0): ");
    if (scanf("%d", &n) != 1 || n <= 0) {
        return 1;
    }

    const double x = 1.0 / 3.0;
    double sum = 0.0;

    for (int i = 0; i <= n; ++i) {
        double power_x = 1.0;
        for (int j = 0; j < i; ++j) {
            power_x *= x;
        }

        double sign = (i % 2 == 0) ? 1.0 : -1.0;
        sum += sign * power_x;
    }

    printf("%.7lf\n", sum);
    return 0;
}
```

### Програма 2
```c
#include <stdio.h>
int main(void) {
    int n;
    printf("Enter n (n>0): ");
    if (scanf("%d", &n) != 1 || n <= 0) {
        return 1;
    }

    const double x = 1.0 / 3.0;
    const double factor = -x;
    double term = 1.0;
    double sum = 0.0;

    for (int i = 0; i <= n; ++i) {
        sum += term;
        term *= factor;
    }

    printf("%.7lf\n", sum);
    return 0;
}
```
